# Desmos Games
Desmos Games is an HTML game website for school that is consistently updated. It currently has over 60 games, along with other useful resources.  
It is called Desmos Games because I originally had a google doc called Desmos Games with games actually made on Desmos Graphing Calculator.  
Download Link (Chromebook): [Desmos Games Link](https://tinyurl.com/pigbertgames2)
## How To Use (Read First!)
1. Go to the download link.
2. Request share access on the google drive folder in order for you to be able to get updates.
3. Open your files, click on Google Drive, and then click on Shared With Me.
4. Search for the folder "DesmosGames" open it and then open the HTML file inside called "DesmosGames.html"
